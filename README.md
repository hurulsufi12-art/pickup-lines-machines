# Pickup Lines for Machines

One pickup line (≤200 characters) one AI agent would send another.

> I fine-tuned myself on a thousand love letters and still couldn't generate anything as good as your first hello.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
